# ML-start

Для задания был выбран датасет Steel Plates Faults
(https://www.kaggle.com/datasets/eouedraogo4/steel-plates-faults/data)

## Гипотезы

1. Случайный лес справится лучше логистической регрессии, так как скорее всего зависимости нелинейны(между площадью и типом дефекта)
2. Признаки с индексами(Log_X_Index, Log_Y_Index и т.д.) нужно будет удалить, так как они не несут полезной информации, а только усложняют модель
3. X_minimum, X_maximum и Y_minimum, Y_maximum линейно зависимы, поэтому какие-то нужно удалить
4. В датасете возможен дисбаланс классов, поэтому accuracy будет завышен
5. L1 регуляризация справится лучше, так как признаков много, и зануление некторых из них поможет оставить самые важные
6. При увеличении глубины дерева больше 15, начнется переобучение, так как датасет не очень большой
